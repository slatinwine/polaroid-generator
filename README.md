# 拍立得相纸生成器 · Polaroid Generator

一张照片，一秒变成经典拍立得。纯浏览器本地处理，照片不会上传到任何服务器。

**在线使用：** <https://slatinwine.github.io/polaroid-generator/>

## 功能

- 📷 **三种导入方式**：点击上传、拖拽图片、直接 `Ctrl+V` 粘贴截图
- ✍️ **相纸手写字**：底部留白区写字，自动用书写风字体渲染，可留空
- 🔄 **旋转角度**：±15° 随意调，导出时连同投影一起渲染成"随手放在桌上"的效果
- 🎞️ **复古老化滤镜**：暖色偏移 + 褪色，0–100% 可调
- 🎨 **四种相纸底色**：经典白、米黄、奶咖、暖灰
- 🎲 **随机来一张**：一键随机旋转与老化程度
- ⬇️ **2 倍分辨率导出 PNG**：透明背景 + 双层投影，可直接用于拼贴、发朋友圈

## 使用

打开网页 → 把照片拖进去（或粘贴截图）→ 写几个字 → 点「下载 PNG」。

## 隐私

所有处理都在浏览器 Canvas 内完成，页面不请求任何网络接口，照片从头到尾不离开你的电脑。

## 技术

单文件 HTML，零依赖、零构建、零后端，Canvas 2D 渲染。下载即用，也可以双击本地直接打开。
